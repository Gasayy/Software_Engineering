## Самостоятельная работа №1
### Дайте подробный комментарий для кода, написанного ниже.
### Комментарий нужен для каждой строчки кода, нужно описать что она
### делает. Не забудь те, что функции комментируются по-особенному.

```python
from datetime import datetime
from math import sqrt

def main(**kwargs):
    """
    Вычисляет длину векторов по их координатам и выводит результаты.
    
    Функция принимает произвольное количество именованных аргументов,
    где каждый аргумент представляет собой список из двух чисел (координаты вектора).
    Для каждого вектора вычисляется его длина по теореме Пифагора.
    
    Parameters:
        **kwargs : dict
            Словарь именованных аргументов, где значения - списки из двух чисел
            Пример: one=[x1, y1], two=[x2, y2], ...
    
    Returns:
        None
            Функция не возвращает значения, а выводит результаты в консоль
    """
    for key in kwargs.items():
        # key[1][0] - первая координата вектора, key[1][1] - вторая координата вектора
        # Вычисление длины вектора по формуле: sqrt(x² + y²)
        result = sqrt(key[1][0] ** 2 + key[1][1] ** 2)
        print(result)

if __name__ == '__main__':
    start_time = datetime.now()
    main(
        one=[10, 3],
        two=[5, 4],
        three=[15, 13],
        four=[93, 53],
        five=[133, 15]
    )
    time_costs = datetime.now() - start_time
    print(f"Время выполнения программы - {time_costs}")
```
